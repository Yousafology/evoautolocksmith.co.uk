# Evo Auto Locksmith London (evoautolocksmith.co.uk)

High-converting, mobile-first website for **Evo Auto Locksmith London**.

## Features
- **24/7 Rapid Roadside Emergency Dispatch**: Integrated quote estimator, direct telephone hotline (`07367 674000`), and instant WhatsApp diagnostic dispatch.
- **Genuine Google Maps Coverage**: Real-time response times mapped across London boroughs and the entire M25 orbital ring.
- **Dedicated Roadside Booking Page**: Complete multi-step dispatch form with GPS location sharing and vehicle registration lookup.
- **Animated Client Reviews**: Google 5-star verified customer reviews carousel.
- **Mobile Action Dock**: Instant 1-tap call and WhatsApp trigger for roadside emergencies.

## Local Development
Serve files with any static HTTP server:
```bash
python -m http.server 5003
```
